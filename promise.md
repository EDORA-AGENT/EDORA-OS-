## 🖥️ The Bootable Goal

One of the biggest goals for EDORA OS 2.0 is to move beyond the current simulator architecture.

### EDORA OS 2.0 is planned to become a **real bootable operating system**.

The target is an independently bootable image:

```text
EDORA-OS.iso
```

The planned boot process:

```text
BIOS / UEFI
     │
     ▼
EDORA Bootloader
     │
     ▼
EDORA Kernel
     │
     ▼
Hardware Initialization
     │
     ▼
Memory Management
     │
     ▼
Filesystem
     │
     ▼
EDORA System
     │
     ├── Shell
     │
     └── Desktop GUI
```

The long-term objective is simple:

> **EDORA OS should eventually boot by itself instead of running on top of another operating system.**
